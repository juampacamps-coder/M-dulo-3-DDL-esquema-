El entregable muestra sus cuatro tablas creadas (categorias, clientes, ventas y categorias) y su posterior carga de informacion en ellas.
A través de su correcta ejecución, se realizarán consultas a futuro.

El archivo se crea, se borran las tablas en caso de haberse creadas previamente, se crean las tablas de cero y se carga la información.
